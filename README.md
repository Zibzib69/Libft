# Libft

## Description
Libft est ma bibliothèque re-écrite en C. Elle regroupe differentes fonctions de la libc, des fonctions supplémentairesque j'ai moi meme creer et des fonctions de gestion de listes chaînées.

## Instructions
- `make` : compile la bibliothèque.
- `make clean` : supprime les fichiers objets.
- `make fclean` : supprime les fichiers objets et `libft.a`.
- `make re` : nettoie puis recompile la bibliothèque.

Pour utiliser la bibliothèque, inclure `libft.h` dans le fichier C et compiler avec `-L. -lft`.
